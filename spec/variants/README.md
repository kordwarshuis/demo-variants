# Swiss edition

English in `spec/` is the source. These four folders are the languages of Switzerland. Missing files stay in English.

| Folder | Language | State |
| --- | --- | --- |
| `de/` | German | Finished prose, plus soil and compost. Markup examples stay in English. |
| `fr/` | French | Introduction reviewed. An earlier AI draft sits beside it and is not published. |
| `it/` | Italian | Unreviewed AI draft of the introduction and of soil. The terms section has only a start. |
| `rm/` | Romansh | Only a short unreviewed draft of the introduction. |

`menu_title` in `specs.json` is `Switzerland`.
